# Live-show document examples

Downloaded September 29, 2026 from public production/education sources. These are original third-party reference documents, not requirements for The Swell and not assets to rebrand. No redistribution license is asserted. Sources, retrieval date, byte counts and SHA-256 hashes are recorded in [sources.json](sources.json).

| Local document | Why it is useful | Source |
| --- | --- | --- |
| [MusicNSW tech rider / input list / stage plot template](musicnsw-tech-rider-stage-plot-template.pdf) | Six-page educational starter; useful section structure and channel-list fields. The website labels its download a Word template, but the actual download is PDF. | [MusicNSW](https://www.musicnsw.com/resources/tech-rider-stage-plot-template) |
| [Molly Tuttle stage plot and input list](molly-tuttle-stage-plot-input-list.pdf) | Two-page real-world pairing of spatial diagram and numbered inputs; includes dimensional staging. Revision printed 9.8.25. | [Artist production downloads](https://mollytuttleadvance.com/downloads) |
| [Molly Tuttle production rider](molly-tuttle-production-rider.pdf) | Shows how detailed touring production responsibilities are organized separately from the plot. Fifteen pages; intentionally much more than a small-band starting packet. | [Artist production downloads](https://mollytuttleadvance.com/downloads) |
| [Berklee Red Room venue tech package](berklee-red-room-venue-tech-package.pdf) | Ten-page example of the venue-side specification to request before reconciling band requirements. Treat its equipment inventory as an example, not a live availability guarantee. | [Venue artist page](https://www.berklee.edu/red-room-cafe-939/booking-and-rental/for-bands) |

Additional public template: [MusicNSW show worksheet](https://www.musicnsw.com/resources/worksheet-template), with a linked [Google Docs worksheet](https://docs.google.com/document/d/10Y5Lsejtgov-JEiKsZv1K--3RD7RXkvJ4B4atLDjlDc/edit). This is a linked reference, not a locally downloaded file.

Suggested reading order: MusicNSW for the basic sections; Molly Tuttle's two-page plot/input pair for presentation; Berklee for the house information to request; the longer rider only for relevant production details.

An original fictional trio example is included locally as [SVG](fictional-trio/example-stage.svg), [JSON](fictional-trio/example-stage.json), and [Markdown/ASCII with technical tables](fictional-trio/example-stage.md). It demonstrates two keyboard inputs for stereo and two wedges sharing a single monitor mix. Its technical choices do not describe The Swell.
