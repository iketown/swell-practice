# Stage plot and printable technical rider

These rules apply to /stage-plot, its components under src/components/rider, its data in src/lib/rider and its publication API.

- The public URL is https://theswell.live/stage-plot. Anyone can view and print the current published revision without signing in. Only a signed-in site administrator can enter the editor, change the shared rider or publish. An unpublished edit must never appear in the public packet.
- Keep **Print rider** visible at the top on desktop and phone. Use the browser’s print dialog, including Save as PDF. The admin editor prints its current layout, including unsaved edits, through the same canvas component. Mark unsaved packets as drafts and link their QR to /sp?draft=1. Public and history views keep their revision-specific print behavior. Print US Letter. Use landscape for the overview, stand placement and cable routing maps, and portrait for the cover, supplier requirements, input key and schedules. Select orientation by section so filtered packets paginate correctly. Keep the draft or revision status and latest-version URL on every printed sheet. Print at actual size with ⅜-inch top and side margins and a ½-inch bottom clearance on every US Letter sheet, including the QR, legend and page number. Turn browser headers/footers off.
- Keep the stage plan full-width. The web header puts **Stage Plot** on the left, **Revised [published date]** in the middle and a large **Print rider** split button on the right. Its dropdown selects the stage plot, equipment advance and audio input key independently. All three start checked. Keep editor controls outside the diagram.
- Diagram pages (overview, stands, cables) use most of Letter landscape: compact header, normal print margins and a full remaining-height canvas. Put the grid/key, check URL and QR together at the bottom margin. Trim unused SVG editing perimeter in print while preserving orientation labels and real outlying items, boxes and route nodes; never stretch stage proportions. Retain the edition on every sheet and repeated column headings on table continuations. Check individual sheets and the complete packet.
- Use the PDF skill for layout verification. Generate a PDF with Chromium using print media and preferCSSPageSize, check each media box (792 × 612 pt for maps and 612 × 792 pt for text), render the pages, and inspect the full plot, all input IDs, equipment totals and page breaks. Test grayscale and background graphics disabled. Do not make a separate manually maintained PDF.

Use the band's current input IDs; the old second Illustrator artboard is historical.
