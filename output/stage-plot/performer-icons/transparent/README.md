# Transparent stage-plot icons

Ten RGBA PNG files: Joe, Ike, Jackson, Chris and Sam, each in color and black-and-white. Original size is 1024 × 1536 pixels. Approved white-background source illustrations are retained in the parent folders.

Backgrounds were removed locally with the user's explicit approval. Interior white details are preserved, enclosed background gaps cleared, and white matte contamination removed along antialiased edges. Black-and-white files contain neutral gray values only. All ten files were checked for true alpha transparency and visually reviewed against a dark background.

Use the PNGs in `color/` or `bw/` in Illustrator. `transparency-proof-dark.jpg` is a review sheet, not a transparent asset. The ZIP contains the ten PNGs in their respective folders.
